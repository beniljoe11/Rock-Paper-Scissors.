# Rock Paper Scissors Game 🎮

A simple Python-based Rock Paper Scissors game where the user plays against the computer using random choices.

## Features
- Interactive command-line gameplay
- Random computer selection using Python `random` module
- ASCII art visuals for Rock, Paper, and Scissors
- Win/Lose/Tie result detection
- Continuous gameplay using loops

## Technologies Used
- Python
- Random Module
- Conditional Statements
- Loops

## How to Run

1. Install Python on your system
2. Download or clone this repository
3. Run the Python file:

```bash
python rock_paper_scissors.py
```

## Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## Example Gameplay

```bash
Select your option!
Type 0 for Rock
Type 1 for Paper
Type 2 for Scissors
```
